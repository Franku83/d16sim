# ADR-011 — No copiar firmware Speeduino ni activos Honda sin revisar licencias
- **Fecha:** 2026-10-10 · **Estado:** ACEPTADO
- **Decisión:** implementación propia desde conceptos/ecuaciones; contenido autorizado.
- **Motivo:** Speeduino GPL-2.0; manual Honda protegido; CAD con derechos.
- **Alternativas:** vincular/derivar GPL (requiere asesoría; no previsto).
- **Consecuencias:** Speeduino como referencia conceptual (S18) sin copiar; inventario legal; THIRD_PARTY_NOTICES desde S02.
- **Trigger:** cualquier propuesta de reutilizar código/activo reabre con revisión legal.
- **Refs:** [R04][R04a][R01]; EVIDENCE_POLICY §5.
