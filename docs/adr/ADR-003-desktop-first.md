# ADR-003 — Desktop-first, interfaz web opcional
- **Fecha:** 2026-10-10 · **Estado:** ACEPTADO
- **Decisión:** desktop-first; web opcional sin limitar bibliotecas numéricas.
- **Motivo:** no limitar análisis pesado.
- **Alternativas:** web-first; móvil.
- **Consecuencias:** Tauri/Three.js solo en Fase D; migración posible.
- **Trigger:** benchmarks que obliguen a recortar perfiles para web (subset validado y anunciado).
- **Refs:** Foundation §1; [R13] Tauri.
