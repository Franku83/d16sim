# ADR-012 — No monetizar/etiquetar resultados como ingeniería certificada
- **Fecha:** 2026-10-10 · **Estado:** ACEPTADO
- **Decisión:** primer producto no es calibración/safety-critical; publicar dominio de validez.
- **Motivo:** sin validación no hay certificación honesta.
- **Alternativas:** etiquetado predictivo temprano (rechazado).
- **Consecuencias:** declaración de no aptitud (charter); S30 decide etiqueta final.
- **Trigger:** evidencia de validación en dominio puede ampliar etiqueta por subsistema, nunca global.
- **Refs:** Foundation §1; [R17] SAE J1349 (consultar texto/licencia si se usa).
