# ADR-006 — Propiedades/mecanismos generales antes de averías concretas
- **Fecha:** 2026-10-10 · **Estado:** ACEPTADO
- **Decisión:** una junta puede fugar sin script "bad_gasket"; modelos reducidos identificados permitidos.
- **Motivo:** causalidad emergente, no penalizadores.
- **Alternativas:** catálogo de fallos guionizados (rechazado).
- **Consecuencias:** fault catalog solo para pruebas/escenarios (S23–S29).
- **Trigger:** mecanismo sin parámetros defendibles queda UNSUPPORTED en vez de parche causal.
- **Refs:** Foundation §1, §4, §8.5.
